Adaptive pressure advance calibration

This generates a grid of small test patches: each column is printed at a different speed (and therefore a different volumetric flow), and each row at a different acceleration. The whole grid prints at one fixed pressure advance value (adaptive PA is disabled for the calibration print).

How to use:
1. Set the speed and acceleration ranges and a fixed PA, then generate and print.
2. Re-print at a few PA values to bracket the best result.
3. For each cell, note the speed×height (volumetric flow), the acceleration and the PA that looked best. Each cube is named s<speed>_a<accel>.
4. Paste the resulting PA, volumetric_flow(mm3/s), acceleration(mm/s2) rows into the filament's Adaptive PA measurements field (Filament → Pressure/Linear advance).
