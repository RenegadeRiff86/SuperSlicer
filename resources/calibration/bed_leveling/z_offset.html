Klipper Z Offset
Needs: Klipper Bed leveling

This prints nine first-layer squares. Each one uses a different Z offset so you can see which height looks right, then measure it and save that value on the filament.

How it works

Pick the printer, print and filament profiles you actually use. Center is the offset on the middle pad. Step is how much the offset changes from one pad to the next. Layer height starts as your first layer height; you can raise it a bit if you are afraid of scraping the bed.

Click Generate. SuperSlicer builds the project and slices it. Send the G-code to the printer the usual way.

Pad 5 uses the center value. Going from pad 1 to pad 9 adds one step each time. So pad 1 is center − 4 × step, and pad 9 is center + 4 × step.

After the print

Look at the first layers and pick the pad that looks best. Measure the thickness of that pad at the outer edge with calipers.

Then open Calibration > Apply Z offset. Type the pad number and the height you measured. SuperSlicer writes the result to the current filament. Look at Filament Settings → Z offset and save the preset if you want to keep it.

If the pad is thicker than the target layer height, the nozzle was too high. If it is thinner, the nozzle was too low.

Notes

Watch the first pads. If the nozzle is heading into the bed, stop the print.

This test turns off skirt and brim so the pads stay separate. You may want to put those back afterwards.
