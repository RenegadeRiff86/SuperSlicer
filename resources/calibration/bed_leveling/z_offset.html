Klipper Z Offset Calibration

This generator creates nine 30 by 30 mm pads in a 3 by 3 grid. Each pad is one selected layer tall and carries its own SET_GCODE_OFFSET command, so no external G-code post-processing script is needed.

Before generating

  • Select the Klipper printer, print, and filament profiles that you intend to use.
  • Enter the center offset and the difference between neighboring pads.
  • Layer height defaults to the active print profile's first-layer height resolved for nozzle 1. You may change it for this test.
  • Outer walls defaults to 5 for a wider, more repeatable edge measurement area.
  • No calibration macro or post-processing script is required. The generated G-code uses Klipper's built-in SET_GCODE_OFFSET command.

Pad 5 uses the center value. Pads 1 through 9 increase by one step each, so pad 1 is center - 4 * step and pad 9 is center + 4 * step.

Print, measure, and save

The generator closes after creating the project so you can slice and print it normally. Klipper reports the pad number, position, active offset, and target height as each pad begins. After the print, find the most uniform pad and measure its outside edge.

Open Calibration > Apply Z offset calibration result. SuperSlicer remembers the generated center, step, and target layer height. Enter the measured pad number and outside-edge height, then apply the result to the active filament preset. SuperSlicer uses the same correction as the former Klipper macro:

corrected offset = tested offset - (measured height - target height)

The active filament preset becomes dirty. Review the value under Filament Settings > Z offset compensation, then save the preset normally.

Why Klipper still receives a command

SuperSlicer now owns and saves the value in the filament preset. Generated G-code sends that value after START_PRINT, so it wins over any older context macro. Klipper only performs the physical coordinate shift. This keeps SuperSlicer's travel, Z-hop, and internal position tracking coherent while removing Klipper saved variables as the source of truth.

Notes

  • The generated project disables skirts and brims so every pad remains independent.
  • If the old z_offset_test_postprocess.py is present in the active print profile, it is removed only from the generated project to prevent duplicate offsets. Other post-processing scripts are preserved.
  • Inspect the full offset range before printing. Stop the print immediately if any pad places the nozzle dangerously close to the bed.
