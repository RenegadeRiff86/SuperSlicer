Apply Z Offset
Needs: A printed pad test

Use this after you printed the nine-pad test. SuperSlicer still has the center, step and target height from when you generated it.

The grid below lists what offset each pad was printed at, arranged the way the pads sit on the bed. Find the pad that looked best on the plate, type its number (1–9), and enter the thickness you measured on it.

If the pad is thicker than the target, the nozzle was too high and the offset goes down. If it is thinner, the offset goes up.

Every filament behaves differently, so the offset belongs to one filament rather than to the printer. Apply to filament writes it to the filament this test was printed with — named above the grid — selecting that preset first if you have since switched to another one.

Check Filament Settings → Z offset, then save the preset if you want to keep the value.
