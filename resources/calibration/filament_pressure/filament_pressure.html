Pressure Advance Calibration
Requirements: Perfect Bed Leveling and Layer Squish

Save your print settings before clicking "Generate". The models are built from your saved configuration, so unsaved changes are not used.

Note: This calibration will automatically pull all your currently saved configuration parameters and generate a model for you to print. For optimal results, depending if you're chasing speed/quality or a mix of both, it is recommended to keep similar speeds for most extrusion roles, (although this is not mandatory).

How to Tune Your Printer for Pressure/Linear Advance

To get started:

  • Select the number of calibration lines to create, the max is 10.
  • Each row represents the config parameters for one extrusion role. Rows are pre-filled by walking down the extrusion role list starting at ExternalPerimeter, so row 1 is ExternalPerimeter, row 2 is GapFill, row 3 is InternalBridgeInfill, and so on. Change any row's role with its drop-down.
  • Select the start/end and increment values, you can manually edit these values if you want larger or smaller values. When the active filament has Pressure Advance enabled, these fields start from that filament's value instead of the built-in defaults.
  • Klipper only: tick Calibrate Smooth Time instead of Advance on a row to sweep SMOOTH_TIME rather than ADVANCE. Klipper's default smooth time is 0.04s; shorter values (around 0.01s) suit fast printing, longer ones (around 0.4s) suit slower printing. The row switches to fixed recommended values (0.010 to 0.080, step 0.005, on ExternalPerimeter) and its fields are locked while the box is ticked; un-ticking restores whatever the row held before.
  • Since each model will have its own config, one calibration model might print faster or slower than others. This is expected and normal.
  • Works with the Arachne perimeter generator, so leave it enabled if you use it.
  • Helpful tip: If you are running multiple calibration lines on a single plate, take a screenshot of the main configuration page (or leave it open and drag the window out of the way) to match the row number to the ID label on the bottom right of the loaded model. (counting starts at '0' ☺)
    You can also inspect each 'base model' and view the object modifiers for each 90° bend model, the 'region_gcode' will have a comment for the extrusion role.

If you use PA/LA commands in your feature_gcode you need to remove them, otherwise your calibration will be invalid.

Role coverage:

  • Calibrated with their own flow: InternalInfill, ExternalPerimeter, Perimeter, SolidInfill, SupportMaterial, SupportMaterialInterface, TopSolidInfill. The generated geometry uses that role's own flow, width and spacing.
  • Calibrated with an approximated flow: BridgeInfill, InternalBridgeInfill, ThinWall, GapFill, Ironing, FirstLayer. SuperSlicer has no dedicated flow for these in the generator, so they borrow the support-interface flow. The pressure advance sweep itself is still applied to the correct extrusion role, but the line width may not match what your real parts print at. Treat the result as a starting point and confirm it on a representative part.
  • OverhangPerimeter is generated with the external perimeter flow. That mapping has not been confirmed against real overhang extrusions yet.

What is the "CheckAll" option?
Pick CheckAll as a row's extrusion role to build one 90° model per extrusion role on a single plate, so you can see at a glance which roles need Pressure Advance tuning.
It differs from a normal row in three ways:

  • The per-region g-code is emitted without a value - you type the pressure advance numbers into the "per region g-code" box yourself.
  • Gap fill and thin walls are turned off on the object so the geometry stays identical between roles and stays easy to compare.
  • Per-role layer heights are not applied. Roles that normally need their own layer height - infill with "combine infill every N layers", supports, and the first layer - are generated at the base layer height instead, so their results are not directly comparable to a single-role run.

Advice

Before calibrating Pressure/Linear Advance, it is recommended to tune everything else first!

You may need to disable or adjust your part cooling config for this test, including the features that slow down layer times. Note: Large variances in ER speeds can reduce print quality and dimensional accuracy.

It's recommended to set 'first_layer_min_speed' and 'first_layer_speed' to the same values, since the variance in speeds will mess with the first layer's pressure advance adjustments.
