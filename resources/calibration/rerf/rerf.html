Normal exposure
Needs: Photon Mono 4

This test finds the normal exposure. The Photon Mono 4 runs it only when the file is named R_E_R_F.pm4n. Any other name is a normal print, and every area gets the same exposure.

The steps are fixed. Area 1 uses the resin's normal exposure. Each next area adds 0.25 s. The slicer does not store a different time on each copy, and the step cannot be changed. Changing the resin's normal exposure moves the whole set.

Bottom exposure is not one of these eight times. Use First layer exposure for that test. Every area in this test uses the same bottom exposure.

Generate tiles places a small cube in each area. Use my model places a copy of a model you choose. A model larger than an area is scaled down so it stays in that one exposure. Supports, the pad, and hollowing are turned off.
